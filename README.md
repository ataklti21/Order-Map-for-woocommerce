# WooCommerce Orders Map Plugin

A comprehensive WordPress plugin that provides order visualization with shipping addresses, driver management, manual assignment, route planning, and live tracking for WooCommerce stores.

Features:
- Laundry workflow: Pickup & Delivery distinction
- Driver notifications (Email, SMS, Telegram, WhatsApp)
- Driver dashboard with live tracking, KPIs, and reporting
- Map dashboard with clustering, bulk assignment, tooltips, route preview
- REST API endpoints for integrations
